### 导入和截图

1. 打开 CubeMonitor 的 Dashboard，不启动采集；已在采集时先停止。
2. 点击 IMPORT DATA，依次导入六个 `angles.stcm`，分别截图；文件名均以 `Step2_Six` 开头。
3. 点击 Zoom，框选表中的时间范围，纵轴选累计起始角度减 0.5°至目标角度加 0.5°。六张图时间跨度统一为 0.4 s，角度跨度统一为 11°。
4. 保留横纵坐标和两条曲线图例，标注物理角度变化、10°阶跃、表中的 100 ms 截止线，以及“同次固件收敛时间：XX ms”。截止线按首次采到新目标的时间加 100 ms 定位，Monitor 采样约 7 ms，精确收敛时间引用固件 1 ms 采样记录。
5. 需要精度细节时导入同组 `error.stcm`，放大到阶跃后 80～500 ms，纵轴 −0.15°～+0.15°，标注 ±0.1°。精确时间范围见同目录 `six_examples.csv`。
6. 如果文件列表为空，在 Monitor 设置中确认日志目录为 `C:\Users\59088\log`，再打开导入窗口。

截图组可用图注：“同一组 PID 与前馈参数下，不同角度的六组 10°阶跃实测响应。原始实测记录离线导入 CubeMonitor 展示；收敛时间引用同次固件 1 ms 采样记录。”

这六组是筛选后的展示样本。完整全圈成绩仍为 34/36 达标：10°→20°为 118 ms，110°→120°为 111 ms。完整成绩保存在 `tuning/20261013/circle-results.csv`，截图组不标注“全圈全部达标”。
