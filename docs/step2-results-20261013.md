## 10°阶跃验收

恢复电调供电后，保持同一组参数，连续测试 0°→10°→0°共八次。

| 次数 | 目标变化 | 收敛时间 |
|---|---|---:|
| 1 | 0°→10° | 65 ms |
| 2 | 10°→0° | 61 ms |
| 3 | 0°→10° | 93 ms |
| 4 | 10°→0° | 96 ms |
| 5 | 0°→10° | 93 ms |
| 6 | 10°→0° | 90 ms |
| 7 | 0°→10° | 77 ms |
| 8 | 10°→0° | 93 ms |

八次反馈均有效，均满足 100 ms 内收敛到目标 ±0.1°。收敛时间来自固件 `step_request` 触发的 500 点、每周期一次记录：计算最后一个误差超过 0.1°的采样之后的时间，并核对 Monitor 后续保持曲线。验收窗口为固件记录的约 500 ms，后续 Monitor 曲线亦保留在本地原始记录中。

其他角度测试存在超时：同参数在 30°↔40°时测到 76～117 ms，不能把 0°附近的结果写成全角度均达标。电池关闭期间的八次测试无电机反馈，全部作废。

本地原始数据位于 `tuning/20261013/`，不提交大体积临时 JSON；正式摘要保存在同目录的 CSV。Monitor 流程备份和最终流程也保留。

## 作业素材

1. Monitor 截图：显示 `target_angle_deg` 与 `actual_angle_deg` 的 10°阶跃，将横轴放大到约 0.3 s，标出阶跃后 0.1 s，核对目标 ±0.1°。
2. 抗扰视频：位置模式下拍打/晃动拨盘，松手后回位且不持续抖动。需要拍摄实体教具。
3. Kp 演示视频：先保存上表参数，再分别增加内环、外环 Kp 展示抖动，在 Keil 运行状态下恢复内环 0.08、外环 110。该项明确要求 Keil 恢复参数；Monitor 改参记录不能替代这段视频。

## 复现阶跃

1. 重新上电后设置 `stop_flag=1`，负载重心放到轴正下方，写 `zero_request=1`。
2. 恢复上表参数，写 `control_mode=4`、`target_angle_deg=0`，再写 `stop_flag=0`。
3. 写 `step_delta_deg=10`，然后单独写 `step_request=1`。等 `trace_state=2`，读取 `settling_time_ms`；应不超过 100。
4. 写 `step_delta_deg=-10`，单独写 `step_request=1`，验证回到 0°。
5. `step_request` 会自动归零。`settling_time_ms=4294967295` 表示记录结束前未收敛；无反馈时任何收敛读数均无效。
