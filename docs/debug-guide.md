# Step1 / Step2 调试与验收指南

## 1. 对应作业要求

| 作业 | 要求 | 操作 |
|---|---|---|
| Step1 | 按负载写前馈，任意角度保持静止，提交视频 | 标零、标前馈、位置双环保持多个角度 |
| Step2-a | 10°阶跃，0.1 s 内进入目标 ±0.1°，CubeMonitor 截图 | 内外环整定，触发 10°阶跃，同步观测与板内记录 |
| Step2-b | 手拍/晃不抖动，不容易转动，提交视频 | 小扰动后恢复，不强行堵转 |
| Step2-c | 加大内外环 Kp 展示抖动，再在 Keil 改回稳定参数 | 两环分别演示，准备参数表，在线写回 Kp |

先调速度内环，接位置外环，再校准前馈，最后优化阶跃和抗扰。上电默认参数仅用于开始调试。

## 2. 电机配置与接线

默认 **M2006 + C610、ID=1**。M3508 + C620 请先把 `motor_config.hpp` 中 MOTOR_MODEL 改为 3508，重新编译。

- 2006：减速比 36，电流指令 ±10000 对应 ±10 A。
- 3508：减速比 3591/187，电流指令 ±16384 对应 ±20 A。
- ID 在 `MotorConfig::motor_id` 修改。反馈 0x200+ID，ID 1~4 命令 0x200，ID 5~8 命令 0x1FF，槽位自动选择。
- 同组其余电机指令是零；本工程只控制单个教具，不与另一控制器同时发送同组命令。
- `direction` 同时反转角度、速度与指令电流。不要仅反转反馈造成正反馈。

断电接线、固定底座与负载，确认动力线、传感器线、CAN_H/L、供电极性与两端终端电阻。电池供电给板和电调，ST-LINK 不给电机供电；不带电拔插动力线。

## 3. Keil 和 CubeMonitor

1. Keil 编译并下载，进入 Debug，运行程序，Watch 添加下表变量。
2. 按培训指南安装 ST-LINK Server；Keil 的 ST-Link Debugger Settings 勾选 Shareable ST-Link。
3. CubeMonitor settings.js 设置 `connectionType: "tcp"` 后重启，加载本次下载的 `.axf`，选择实际 ST-LINK。
4. 曲线分别配置：目标/反馈角度；角度误差；目标/反馈速度；总电流/前馈电流。角度统一用同一轴，误差轴能分辨 ±0.1°。
5. 不在运动中暂停 CPU；停机并确认电流为零后才暂停。Keil 停止会打断控制周期，不能用单步调 PID。

| 变量 | 用途 |
|---|---|
| stop_flag | 1 停机，0 允许运行，每次最后才清零 |
| control_mode | 1 直接电流，2 纯前馈，3 速度内环+前馈，4 位置双环+前馈 |
| zero_request / zero_valid | 停机静止时请求标零，valid 应由程序置 1，不手动绕过 |
| feedback_online / feedback_age_ms | 应在线，反馈年龄小于 20 ms |
| rx_count / rx_invalid_count | 收帧数应增加，无效帧不持续增加 |
| tx_count / tx_error_count | 成功入邮箱数/失败数；入邮箱不是电调执行确认 |
| fault_flags | 0 正常；1 反馈、2 未标零、4 超角度、8 3508 过温、16 参数错误、32 CAN 故障，可叠加 |
| target_angle_deg | 输出轴目标角度，安全范围默认 ±150° |
| target_speed_deg_s | 速度模式目标，单位输出轴 °/s |
| manual_current_a | 直接电流模式指令 |
| current_limit_a / speed_limit_deg_s | 总电流/目标速度限幅，初值 0.5 A / 120°/s |
| ff_enable / ff_peak_current_a / ff_scale | 前馈开关/峰值/校准倍率，倍率允许 -3~3 |
| position_pid_params.kp / ki / kd | 位置参数，起点 4/0/0 |
| speed_pid_params.kp / ki / kd | 速度参数，起点 0.02/0/0 |
| pid_reset_request | 写 1 清积分和历史状态 |
| command_current_raw / feedback_current_raw | CAN 指令/反馈原始有符号数，不混用两种电调反馈换算 |
| control_cycles_max | 最大控制耗时除以 168 得微秒，应远小于 1000 μs |

参数每周期读取，Watch 修改后下一周期生效。大范围改参数先停机，只有安全的小幅 Kp 演示保持运行。

## 4. 标零、方向和停机

1. stop_flag=1，支撑负载，让重心竖直向下并静止。
2. 确认反馈在线、rx_count 增长，写 zero_request=1。
3. 检查 zero_valid=1、实际角度约零、fault_flags=0。
4. 设置 control_mode=1、manual_current_a=0.05、current_limit_a=0.1，移开手，短时清 stop_flag，随后恢复为 1。
5. 正电流应产生正速度、正角度。电流不足以克服摩擦可小步增加，不直接用大电流。
6. 回到向下位置重新标零，后续恢复 current_limit_a=0.5。

反馈中断 20 ms 会停机并作废零位，重新连通后不会自行输出；重新标零后人工清停机。stop_flag 覆盖包括前馈在内的最终输出，下一 1 ms 周期发送零指令。零电流会失去主动保持力，先支撑负载。

## 5. 速度内环

从向下附近小行程开始，不让摆臂持续绕圈。

1. 停机设置 control_mode=3，目标速度零、ff_enable=1。
2. I/D 为零，内环 Kp 从 0.02 开始。给短时 +20°/s、零、-20°/s，观察跟踪。
3. 响应慢且电流不饱和时 Kp 每次增加约 20%；连续振荡时回退到前一稳定值并留余量。
4. 稳定后仍有持续速度偏差，Ki 从很小值试起，例如 0.00001，再逐步增加。参数是每 1 ms 误差累加式，不能照搬显式带 dt 的代码。
5. D 先保持零，避免放大速度量化噪声。d_filter_k 越大滤波越强、延迟也越大。
6. 保存稳定内环参数，随后固定内环调位置环。

i_max 限的是误差累加，积分最大贡献是 ki×i_max。停机、换模式、掉线自动清状态，单纯改 Kp 不清状态。

## 6. Step1：前馈与任意角度保持

以竖直向下为零位，补偿矩 `τ=mgr sinθ`，前馈电流 `I_ff=峰值×scale×sinθ`，θ 是实际输出轴角度，正弦内部用弧度。

| 教具 | 负载 | 力臂 | 峰值重力矩 |
|---|---:|---:|---:|
| 2006 | 0.100 kg | 0.065 m | 0.063765 N·m |
| 3508 | 0.500 kg | 0.05524 m | 0.2709522 N·m |

2006 以手册 0.18 N·m/A 得到前馈峰值初值 0.35425 A。不能拿电池输入电流直接换转矩；用多角度静止校准修正幅值，覆盖摆臂自重与电调系统差异。

1. 停机切 control_mode=4，位置 Kp=4、I/D=0，速度参数用已调好的值。
2. 目标零度后清停机，稳定后逐步给 10°、20°、30°。
3. 2006 用默认理论前馈，补偿不足逐步增加 ff_scale，过补偿则减少；先确认零位、方向，再加积分。
4. 逐步接近 60°/90°，电流长期限幅时先停下，不继续加 Kp。
5. 3508 的前馈峰值初始零，因为没有其配套电机转矩常数，不套用 2006 参数。先用位置 P+速度 PI 保持多个安全角度，读取稳定 command_current_a，用 `I_hold/sinθ` 估计峰值，避开零度附近，正负多点复核；再填 ff_peak_current_a、开前馈并减少用于重力补偿的积分。
6. 检查 -30°、+30°、-60°、+60°等角度。纯前馈 mode=2 只用于支撑下短时检查趋势，位置保持验收用双环 mode=4。

Step1 视频：连续切换多个安全角度，每次展示停稳保持。默认 ±150°是保护值，按机械实际可用行程缩小 angle_limit_deg；不为展示任意角度撞限位。向上附近可能不稳定，先完成其他姿态。

## 7. Step2-a：阶跃整定与记录

内环固定后，位置 Kp 每次增加约 20%，先 5°再10°阶跃。慢而不饱和可增加，持续振荡就回退；每次只改一环。过冲优先检查内环阻尼与积分。初始外环 Kp=4、限速120°/s不是100 ms达标参数，确认稳定后逐步提高，不取消限幅。

稳定位置模式运行时，在 Watch 写：

```text
step_delta_deg = 10
step_request = 1
```

下一周期将目标增加10°并记录500点，每点包含 DWT 实测毫秒时间戳、目标、反馈、误差、速度、电流、前馈。采集约0.5 s，不在期间改参数。

- trace_state：0 未采集、1 正在采集、2 完成、3 中止或触发条件不满足。
- trace_count 正常完成为500。
- settling_time_ms 是最后一次离开±0.1°后再进入的时间，之后保持至窗口结束；4294967295 表示无有效收敛结果。
- step_overshoot_deg 给出超调，不能用大过冲换速度而不记录。
- 停机、换模式、采集中改目标会中止。step_delta_deg=-10 可测反向；触发是增量，不自动回零。

**CubeMonitor 截图仍是作业必交项**：目标/反馈同图、时间轴清晰、误差可分辨±0.1°。减少同时采集的变量数，确保100 ms内有足够实测点；板内记录补充主机采样不足，不对稀疏点插值冒充高频数据。

### 导出板内记录

完成采集先置停机、确认零电流，再暂停 CPU。查 `&trace_samples[0]` 地址，数组长14000字节，使用 Keil Command 的 SAVE 导出这个连续范围为 Intel HEX。末地址=首地址+13999。例如首地址若为0x20000224：

```text
SAVE capture.hex 0x20000224, 0x200038D3
```

这是示例地址，必须用当前编译的实际地址；也可用调试工具导出同范围原始.bin。转换：

```powershell
python tools/export_trace.py capture.hex capture.csv
```

恢复后重新检查零位和反馈，再触发完整新记录，不拼接暂停前后的波形。

## 8. Step2-b：抗扰视频

在30°、60°等姿态保持，轻拍底座或轻推负载，展示短时偏离后恢复目标。不比力气、不持续堵转。

- 持续抖动：回退最近增加的 Kp，检查积分和速度噪声。
- 缓慢偏移：先校前馈与零位，再少量增加积分。
- 轻推后恢复慢：确认内环稳定，再增加外环刚度，查看是否电流限幅。
- 电流持续顶住限幅：停止施力，避免发热。

## 9. Step2-c：增大 Kp 后在 Keil 恢复

记录稳定的两环参数、前馈和限幅，准备手机拍教具及屏幕录制。

1. 保持外环不变，小步增加 speed_pid_params.kp，出现轻微持续抖动即停止增加，在 Keil 写回稳定 Kp，展示停止抖动。
2. 恢复稳定参数，再保持内环不变，小步增加 position_pid_params.kp，同样用 Keil 在线写回。
3. 两段都完整拍下数值修改、抖动、恢复数值和恢复稳定。不能用重新烧录代替在线恢复。
4. 不直接跳到极大 Kp。不能安全产生轻微振荡时先拍响应变化，异常立即停机/断电。

## 10. 保存与交付

在线修改只影响 RAM，复位会恢复源码。将 app.cpp 内两环参数、前馈幅值/倍率、限幅写回初始值，重新编译下载并复测。

记录表：电机/电调/ID；位置与速度 Kp/Ki/Kd/i_max/d_filter_k；前馈峰值与倍率；电流与速度限幅；正反10°收敛时间；测试姿态和负载。

交付：Step1 保持视频、Step2-a CubeMonitor 截图与原始记录、Step2-b 抗扰视频、Step2-c Keil 在线恢复视频、最终源码与参数表。截图和小型CSV可放 evidence/，大视频单独保存。

源码与记录功能已提供，最终100 ms、±0.1°以及抗扰必须用真实教具测量，不以默认值或模拟测试充当达标证据。
